# PEC ACM Website Code Style and Formatting

The PEC ACM Website codebase mainly uses Biome for code formatting in order to quickly and automatically check for formatting (and sometimes logical) errors in code.

The guiding principles of the filament code style and code formatting can be resumed as:
- no nonsense
- use your own judgement
- break the rules **if it makes sense** e.g.: it improves readability substantially
- use the formatting of the file you're in, even if it breaks the rules
- no nonsense

It's worth noting that modern IDEs and text editors can run these tools automatically on save. It may be worth looking into whether this functionality is supported in your editor for a more convenient development workflow.
